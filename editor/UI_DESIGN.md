# 框架编辑器 UI 设计稿（v2 · 工作室）

> 2026-09-11 立。鱼鱼反馈「现在的 UI 太敷衍」→ 本文是重新设计的方案。
> 约束不变：**零依赖**（单页 HTML + 原生 JS + Python stdlib http.server）、零构建、只绑 127.0.0.1。
> 后端 API **一行不改**（编辑器前端是纯消费方）。

---

## 0. 现在为什么「敷衍」（诊断）

| # | 问题 | 证据 |
|---|---|---|
| 1 | **编辑器自己的样式只有 53 行** | `app.css` 53 行，套用从游戏编辑器搬来的 `style.css` 变量 |
| 2 | **控件全是浏览器默认外观** | `<select>` / `<input type=checkbox>` / 滚动条未做任何定制 |
| 3 | **信息架构扁平**：9 个域挤在一行 tab 里 | `index.html:22` 单个 `<nav id="tabs">`，靠横向滚动 |
| 4 | **无设计系统**：间距/字号/圆角/层次随手写 | 颜色只有 11 个变量，无 elevation / 无状态色阶 |
| 5 | **列表信息量不足**：只有名字 + key + kind + ✗ | 无 kind 色彩语义、无筛选、无排序、无分组 |
| 6 | **无键盘工作流** | 只有 `beforeunload` 拦截；改一个字段要点 4 次鼠标 |
| 7 | **无空/载入/错误态设计** | 空态是一行灰字；错误是红框堆叠文本 |
| 8 | **试跑结果是 `textContent` 大段文本** | `app.js:282` 拼字符串，52px 伤害数字的 CSS 白写了 |
| 9 | **无「变更预览」** | 保存前看不到改了什么（`table.diff` CSS 存在但无人用） |
| 10 | **面板固定宽度不可调** | `list-pane{width:320px}` 写死 |

## 1. 设计目标（三条）

| 目标 | 含义 | 验收 |
|---|---|---|
| **A. 专业工作台质感** | 像 IDE/专业工具，不像 demo | 有完整设计系统；控件非默认外观；层次分明 |
| **B. 高频操作零鼠标** | 配置内容要快 | Ctrl+K 跳条目、Ctrl+S 保存、↑↓ 选择、/ 搜索 |
| **C. 状态透明** | 改了什么、哪条有问题、能不能存 | 变更预览 + 状态栏 + 列表问题标记 + 未保存守卫 |

**非目标**（明确不做）：主题切换（保持暗色单一）、多语言、插件化 UI、移动端适配、
拖拽排序（内容顺序由数据决定）、富文本。

├──────┬──────────────────────┬─────────────────────────────────────────────┤
│ 域栏  │ 条目列表              │ 编辑器                                       │

│ 1    │ ├──────────────────┤ │ ├─────────────────────────────────────────┤ │
│ 🧙职业│ │ 全部 ⚠待修 ●未保存│ │ │  [表单 | JSON | 变更]                    │ │

├──────┴──────────────────────┴─────────────────────────────────────────────┤

**为什么改域栏**：9 个域横向 tab 在窄屏要滚；改成竖向 icon 栏后 ① 一屏容纳 10+ 域
② 域状态（数量/问题）有固定位置 ③ 给编辑器腾出横向空间。域栏宽度 76px 固定。

**三栏宽度**：域栏 76 固定 · 列表 300（可拖 220–520）· 编辑器自适应。
两条分隔条可拖拽，宽度存 `localStorage`。

## 3. 设计系统（v2 全部 token）

### 3.1 色板（暗色单主题，5 级 elevation）

| token | 值 | 用途 |
|---|---|---|
| `--bg-0` | `#0b0e13` | 应用底（最深） |
| `--bg-1` | `#11151c` | 面板 / 编辑器底 |
| `--bg-2` | `#171c25` | 抬升（顶栏、列表头、卡片） |
| `--bg-3` | `#1e242f` | 控件底（input/select/按钮） |
| `--bg-4` | `#262d3a` | 悬停 / 激活 |
| `--line` / `--line-2` | `#2a3240` / `#333c4d` | 常规边框 / 强调边框 |
| `--fg-0/1/2/3` | `#eef1f6` `#b3bccd` `#7d879b` `#576074` | 主/次/弱/最弱文字 |
| `--accent` | `#7aa2ff` | 主色（操作、选中、焦点） |
| `--ok` `--warn` `--err` | `#46c98a` `#e6a94a` `#f2706d` | 语义色 |

**内容语义色**（kind → 色）：物理 `#c9d2e0` · 魔法 `#79c8ff` · 治疗 `#46c98a` ·
增益 `#e6a94a` · 被动 `#a08cff` · 召唤 `#5fd0c0` · 真伤 `#f2706d`（含 `魔法·火` 等前缀归并）

### 3.2 尺度

| 维度 | 值 |
|---|---|
| 间距 | 4 · 6 · 8 · 10 · 12 · 16 · 20 · 24（4px 网格） |
| 圆角 | `--r-sm 6` · `--r 8` · `--r-lg 12` · `--r-full 999` |
| 字号 | 11 徽标 · 12 辅助 · 12.5 表单 · 13 正文 · 14 列表项 · 16 面板标题 · 20 条目标题 |
| 行高 | 1.45 紧凑 · 1.6 正文 |
| 阴影 | `--sh-1 0 1px 2px #0006` · `--sh-2 0 8px 24px #0007` · `--sh-3 0 20px 60px #000a` |
| 等宽 | `--mono`（Cascadia Mono / Consolas）—— key、路径、数值、日志 |

### 3.3 组件清单

| 组件 | 规格 |
|---|---|
| `.btn` | 高 30；三级：`primary`（accent 底）/ 默认（bg-3 底）/ `ghost`（透明+悬停底）；`danger` 变体 |
| `.chip` | 药丸，12px；可选中态（accent-dim 底 + accent 边）；用于筛选与 kind |
| `.segmented` | 分段控件：底槽 + 滑块，替代原「一排按钮」 |
| `.kbd` | 键帽：11px 等宽、底 bg-3、下边框加粗 1px |
| `.field` | label(12.5) + 控件 + 帮助(11.5) 三行；`required` 星号；`has-error` 左侧 3px 红条 |
| `fieldset.grp` | 卡片式分组：legend 用 accent 小字 + 上分隔线 |
| `.rail-item` | 76×54；icon 18px + label 11px + 计数角标；激活态左侧 2px accent + bg-2 |
| `.entry-row` | 高 38；名字 + kind chip + key（弱）；`is-bad` 左侧红条；`is-dirty` 右侧黄点 |
| `.toasts` | 右下堆叠，最多 3 条，4s 自动消退，可点击关闭 |
| `.palette` | 居中浮层（宽 620，顶部 12vh）；输入框 + 结果列表 + 底部快捷键提示 |
| `.issues` | 校验问题条：图标 + 计数 + 「定位到第一个」按钮 + 可展开明细 |
| `.statusbar` | 高 26；左路径 · 右（改动 / 校验 / 引擎版本） |

**动效**：仅 3 处，均 ≤120ms `ease-out` —— 抽屉滑入、palette 淡入、toast 上浮。
不做装饰动画（保持工具感）。

## 4. 交互设计

### 4.1 键盘（工作流核心）

| 键 | 动作 |
|---|---|
| `Ctrl/⌘+K` | 命令面板（跳条目 + 执行动作） |
| `Ctrl/⌘+S` | 保存当前条目 |
| `/` | 聚焦搜索框 |
| `↑` `↓` | 列表内移动（自动打开） |
| `Alt+↑/↓` | 切换域 |
| `Ctrl+Enter` | 试跑当前条目 |
| `Esc` | 关面板 / 取消搜索 / 关抽屉 |

### 4.2 命令面板（新增，最大效率增益）

一个输入框，两类结果合并模糊搜索：

```
条目    ⚔ 火焰斩            skills · 物理
        🐺 石炉守卫          monsters
动作    ✓ 全包校验
        ＋ 新建条目
        ⚙ 打开包设置
        ⚔ 试跑当前条目
```

### 4.3 变更预览（新增）

编辑器第三档 `变更`：客户端 diff（加载时快照 vs 当前值），按字段列出
`路径 | 旧值 | 新值`，未改动的字段折叠。**保存前先看改了什么**——现在完全没有。

### 4.4 状态透明

| 位置 | 显示 |
|---|---|
| 列表行 | 悬停显 key；有问题显左侧红条 + ⚠；未保存显右侧黄点 |
| 编辑器头 | kind chip + key + `● 未保存` |
| 动作栏 | 保存按钮在无改动时 `disabled`；有改动时 accent 高亮 |
| 状态栏 | 包路径 · 未保存计数 · 待修计数 · 引擎版本要求 |
| 域栏 | 每个域角标显条目数；有问题时角标转红 |

### 4.5 校验问题定位

校验失败（422）→ 顶部 `.issues` 条：
```
⚠ 2 个字段有问题         [定位到第一个 ▸]
  · $.kind  必须是枚举值之一
  · $.power 类型应为 number
```
点「定位」→ 切到表单档 + 滚动到该字段 + 高亮（复用 `SchemaForm.markErrors`）。

## 6. 实施计划

| 步 | 内容 | 验收 |
|---|---|---|
| U1 | `app.css` 全量设计系统（token + 组件 + 三栏 shell） | 视觉自检 |
| U2 | `index.html` 三栏骨架 + palette + 抽屉 DOM | 结构就位 |
| U3 | `app.js` 交互（域栏/筛选/排序/快捷键/palette/diff/抽屉） | 端到端实跑 |
| U4 | 视觉验收 + 功能回归（编辑/保存/校验/试跑全链路） | 截图 + 实测 |

**兼容性铁律**：`schema_form.js` 一行不改 —— 新 CSS **沿用它的全部 class**
（`schema-form` / `grp` / `field` / `f-label` / `f-title` / `req` / `help` / `ctl` / `ctl k` /
`array-rows` / `array-row` / `addbtn` / `kv-row` / `extra`），只做视觉重排。

**删除项**：`web/style.css`（53 行 `app.css` + 182 行 `style.css` 双样式表 →
合并为单一 `app.css`；`style.css` 是游戏编辑器的副本，框架编辑器不再引用）。
